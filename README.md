## 🚀 Flagship project — [PortfolioAI](https://portfolioai.company)

> **An AI tool that turns resumes into live portfolio websites.** Designed, built, launched, and operated solo — 15+ signups since launch.

| | |
|---|---|
| **Frontend** | Next.js · React · Tailwind CSS |
| **Backend** | Supabase (PostgreSQL, Row-Level Security) · serverless on Vercel |
| **Payments** | Stripe — checkout, webhooks, payment-gated access |
| **AI** | Claude API — Opus for generation, Haiku for resume parsing, prompt-engineered structured HTML |
| **Ops** | Resend email automation · cron-based drip sequences · CI/CD |

**Production problems I've actually solved:**
- 🔒 Built a blur-gate paywall (5-minute preview window, 72-hour expiry) gating full portfolios behind a $4.99 unlock
- 🐛 Diagnosed and resolved a live Stripe recurring-billing defect, and a separate expired-live-key checkout outage, through the Stripe API and dashboard
- 🤖 Prompt-engineered deterministic, structured HTML generation across 12 design palettes, with rules to keep names legible and layouts free of AI-design clichés
- 🖼️ Shipped a full photo pipeline: upload → Supabase Storage → AI background handling → composited into the generated hero
- 🚑 Debugged and fixed a production incident where a native binary (ONNX runtime) crashed the resume-upload route on Vercel — rolled back, root-caused, and shipped a permanent fix
- 📬 Automated a multi-step conversion email sequence that runs on its own, daily
